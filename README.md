# Group Project
Names:
Thomas, William, Jonah, and Ronan. 
## DeckBuilder-Style Game
In this game the player will explore the map, acquire random abilities, and fight enemies.
[alt tag](URL)
## Style/theme
This game will be a dungeon crawler type game. 
## Who might consider playing this game:
Those who like rogue-like games.
## Main action or control:
Includes walking, running, and fighting. 
## Feedback/Challenge:
The player has to battle enemies of increasing difficulty, and builds a deck as they defeat them.
## Player's goal: 
Survive rooms, get to the boss, defeat it and win, while building a deck of different abilities to use.
